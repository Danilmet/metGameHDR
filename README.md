# metGameHUB

Трей-приложение для Windows 11, которое следит за играми и само управляет системным HDR: включает его, когда запускается игра, и выключает после выхода. Заодно добавляет игры не из Steam в библиотеку Steam с обложками и подбирает графические настройки под ваше железо с помощью Claude.

## Возможности

- **Автоматический HDR.** Раз в 2 секунды приложение сверяет запущенные процессы с библиотекой игр. Когда известная игра запускается, системный HDR включается; через 3 секунды после выхода выключается, но только если включило его само приложение. Если HDR уже был включён вручную, он останется включённым.
- **Единая библиотека игр.** Steam, Epic Games, GOG Galaxy, Ubisoft Connect, EA app, Xbox (Microsoft Store), а также любые папки с играми и отдельные приложения, которые вы добавите сами. Библиотека сканируется при каждом запуске в фоне.
- **Non-Steam ярлыки с обложками.** Игры из папок и добавленные приложения можно записать в Steam как non-Steam игры; обложки, баннеры, логотипы и иконки подтягиваются из [SteamGridDB](https://www.steamgriddb.com/).
- **Советчик по графике.** Для каждой игры можно задать цель (FPS и приоритет: качество картинки, баланс или отзывчивость), и Claude найдёт файл настроек игры, прочитает текущие значения и предложит, что изменить. Изменения применяются одной кнопкой, с резервной копией.
- **Самообновление.** Приложение проверяет GitHub Releases и предлагает обновиться по кнопке.

## Установка

Скачайте zip со страницы [Releases](https://github.com/Danilmet/metGameHUB/releases) и распакуйте в любую папку:

- `metGameHUB-<версия>-win-x64.zip` — маленький, нужен установленный [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).
- `metGameHUB-<версия>-win-x64-selfcontained.zip` — большой, ничего ставить не нужно.

Exe не подписан, поэтому при первом запуске SmartScreen покажет предупреждение («Подробнее» → «Выполнить в любом случае»). Установщика нет; галочка «Запускать вместе с Windows» в настройках прописывает автозапуск для текущего пользователя (без прав администратора).

Требования: Windows 11 с монитором, поддерживающим HDR. На Windows 10 приложение запускается, но использует старый API переключения HDR и сплошной фон окна вместо акрила.

## Первый запуск

Запустите `metGameHUB.exe`. Откроется окно со списком найденных игр; при закрытии окна приложение остаётся в трее. Повторный запуск exe не создаёт второй экземпляр, а показывает окно уже работающего.

Иконка в трее показывает текущее состояние HDR (подсказка «HDR: вкл/выкл»). В меню трея: «Открыть», «Пауза слежения» (временно отключает автоматику) и «Выход». Двойной клик по иконке открывает окно.

## Вкладка «Игры»

Карточки всех найденных игр с обложками. У каждой игры есть галочка **HDR**: снимите её, если для этой игры HDR включать не нужно. Такие игры помечены бейджем `nonHDR`. Зачёркнутый бейдж `Steam` означает, что игра из папки или приложение ещё не добавлены в Steam.

Выделите игры и нажмите **«Добавить выбранное в Steam»**, чтобы создать non-Steam ярлыки. Что при этом происходит:

1. Обложки и иконки скачиваются из SteamGridDB (нужен ключ API, см. настройки) при работающем Steam.
2. Steam закрывается (`steam.exe -shutdown`), файл `shortcuts.vdf` перечитывается и записывается атомарно с копией `.bak`.
3. Steam запускается обратно.

На одну папку игры создаётся одна запись; у уже существующих записей сохраняется appid, значит коллекции и время в игре не теряются. Аргументы ярлыков `.lnk` попадают в параметры запуска записи Steam.

При выделении одной игры справа появляется панель деталей: подобраны ли настройки графики и кнопка **«Открыть»**, ведущая на страницу игры.

## Страница игры

Здесь можно переопределить, что приложение знает об игре:

- **Exe** — главный исполняемый файл игры. Он записывается в ярлык Steam и передаётся советчику; на отслеживание запуска не влияет (запущенной игра считается, когда любой процесс идёт из её папки). Нужно, если автоопределение выбрало не тот файл (например, лаунчер вместо игры).
- **Имя для поиска** — название, по которому ищутся обложки в SteamGridDB и файл настроек.

### Подбор графики

1. Укажите **FPS** (пусто — значение по умолчанию из настроек) и **приоритет**: «Картинка», «Баланс» или «Отзывчивость».
2. Нажмите **«Подобрать»**. Если файл настроек игры ещё не найден, сначала выполняется запрос «найти конфиг»: Claude по списку файлов папки игры и типовым местам (`%LocalAppData%`, `Documents\My Games`, `Saved Games` и т. п.) называет один файл настроек. Найденный путь показывается на странице; кнопка **«Найти заново»** сбрасывает его. Если файл ещё не создан игрой, запустите игру хотя бы раз.
3. Второй запрос получает содержимое этого файла и характеристики компьютера и возвращает таблицу **«Сейчас | Рекомендуется»** с пояснением к каждому пункту.
4. **«Применить»** записывает рекомендованные значения в файл. Игра должна быть закрыта. **«Отменить»** закрывает страницу, ничего не меняя.

Резервные копии: при первом применении рядом с конфигом создаётся `<файл>.orig` (исходное состояние, больше не перезаписывается), при каждом применении — `<файл>.bak` с предыдущим содержимым. Откатить изменения можно, вернув любой из них на место вручную.

Поддерживаются `.ini`-подобные файлы и плоские JSON-конфиги «один ключ на строку» (например, `renderer.ini` у игр Remedy). Ключи, которых нет в файле, не добавляются. Если игра хранит настройки в реестре, бинарном файле или облаке, файл не найдётся, и рекомендации придётся выставить в меню игры вручную.

Что отправляется в Anthropic API: название игры и exe, модель видеокарты и объём видеопамяти, процессор, объём ОЗУ, разрешение и частота монитора, версия Windows, список файлов в папке игры и содержимое одного файла настроек (до 32 КБ). Значения ключей, похожих на пароли и токены (`password`, `token`, `secret`, `auth`, `session` и т. п.), заменяются на `***`. Модель может сделать до 2 веб-поисков при поиске конфига и до 3 при подборе. Запросы платные и идут с вашего ключа.

## Настройки

- **Папки с играми** — корневые папки, каждая вложенная папка считается игрой (даже без exe в корне). **Добавить приложение** — отдельный exe или ярлык `.lnk`.
- **Steam → Аккаунт** — в чей профиль Steam писать ярлыки. По умолчанию последний входивший.
- **SteamGridDB → Ключ API** — без ключа обложки для игр не из Steam не скачиваются и ярлыки создаются без картинок. Ключ выдаётся на [steamgriddb.com/profile/preferences/api](https://www.steamgriddb.com/profile/preferences/api).
- **Claude → Ключ API** — ключ [console.anthropic.com](https://console.anthropic.com/). **Адрес сервера** — пусто для официального API или адрес совместимого прокси. **Модель** — пусто для `claude-opus-5-5`; `claude-sonnet-5-5` дешевле.
- **Графика** — FPS по умолчанию (пусто — частота монитора) и приоритет по умолчанию для игр без собственной цели.
- **Поведение** — «Выключать HDR при выходе из игры» и «Запускать вместе с Windows».

## Командная строка

- `metGameHUB.exe --hdr status|on|off` — проверить или переключить HDR вручную; работает независимо от запущенного экземпляра.
- `metGameHUB.exe --tray` — запуск без окна, сразу в трей. Так прописывается автозапуск.

## Файлы

Всё лежит в `%AppData%\metGameHUB\`:

| Файл | Что внутри |
|------|-----------|
| `settings.json` | настройки, включая ключи API |
| `library.json` | кэш библиотеки и переопределения игр: HDR, exe, имя для поиска, цель и последний совет по графике, путь к конфигу |
| `log.txt` | журнал; после 1 МБ переименовывается в `log.old` |
| `covers\` | обложки SteamGridDB для игр не из Steam |
| `update\` | временные файлы обновления, удаляются при следующем старте |

Повреждённый JSON переименовывается в `.bad`, и применяются значения по умолчанию. При обновлении с metGameHDR старая папка `%AppData%\metGameHDR` переносится автоматически, автозапуск переписывается на новый exe.

Приложение не отправляет никакой телеметрии. В сеть оно ходит только к GitHub (проверка обновлений), SteamGridDB (обложки, при заданном ключе) и Anthropic API (советчик, при заданном ключе).

## Как это работает

- HDR переключается через Windows DisplayConfig API — тот же переключатель, что «Параметры → Дисплей → Использовать HDR». На Windows 11 24H2 и новее используется новый API (`SET_HDR_STATE`), который не путает HDR с автоматическим управлением цветом.
- Игра считается запущенной, если путь какого-либо процесса лежит в её папке; при вложенных папках выбирается самая глубокая. Игры со снятой галочкой HDR не учитываются.
- Обложки Steam-игр берутся из кэша самого клиента Steam, игр не из Steam — из SteamGridDB. Для уже добавленных в Steam ярлыков используется картинка из `userdata\<user>\config\grid`.
- Обновление: zip скачивается в `update\`, текущий exe переименовывается в `.old`, новый ставится на его место и запускается. Если новый exe не запустился, старый возвращается на место.

## Сборка

```
dotnet build
dotnet test
dotnet publish src/metGameHUB -c Release -o publish
```

Нужен .NET 8 SDK. Сторонних пакетов кроме xUnit нет. Релизы собирает GitHub Actions по тегам `v*`: два zip (framework-dependent и self-contained), версия берётся из тега. Иконка генерируется скриптом `tools/make-icon.ps1` (запускать с `-ExecutionPolicy Bypass`).
