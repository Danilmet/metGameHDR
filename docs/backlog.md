# Бэклог

Отложенные темы, не вошедшие в текущие ветки. Каждая — кандидат на отдельную ветку. Крупные темы делаются через superpowers: brainstorming → спека в `docs/superpowers/specs/` → план в `docs/superpowers/plans/` → исполнение.

## Порядок крупных тем

Рекомендуемый порядок (от фундамента к надстройкам); уже сделаны «одна цель» (v0.5.0), «текущие настройки после поиска» (v0.6.0), «модель и effort под каждую задачу» (v0.7.0), «уточнение совета в чате» (v0.8.0), «список игр слева на странице игры» (v0.9.0), перенос деталей на страницу игры вместо боковой панели с плавающим чатом (v0.10.0), «How Long to Beat» на странице игры (v0.11.0) и «конфиги Unity в реестре» (v0.12.0).

1. **Оверлей с чатом** — самое крупное, опирается на чат на странице игры и на выбор модели по задачам.

## Советчик по графике

- **Своя модель и effort для чата.** Сейчас уточнение совета берёт настройки подбора (`ClaudeAsk`); отдельная строка «Чат» в блоке «По задачам» — пара строк, если понадобится дешёвая модель для переписки.

## Новые фичи

- **Оверлей с чатом в игре.** Поверх игры окно чата с подсказками по игре, ввод голосом и текстом. Модели автоматически уходит контекст: игра, текущие настройки, железо, последний совет, по возможности скриншот. Отдельная большая тема: хоткей, оверлей поверх полноэкранных игр, распознавание речи, стоимость запросов.

## Мелочи из ревью

Цель (ползунок, v0.5.0):
- Подпись под ползунком и запрос могут взять разную частоту монитора, если она меняется на ходу (`monitorHz` читается один раз при создании окна, запрос — `Hardware.Detect()` в момент отправки).
- Нет тестов на логику ползунка в `GameRow` (`TargetIndex`, `ResetTarget`, хвост «(по умолчанию)»).
- Деления под ползунком могут чуть не совпадать с положениями бегунка по краям (TickBar на всю ширину, Track — с отступом на бегунок).

Текущие настройки (снимок, v0.6.0):
- После «Применить» подписи Unreal могут расходиться: у применённых строк значение от модели («Ultra»), у остальных — из локальной таблицы («Epic»); строки, дописанные из локальной таблицы, — с русскими именами среди английских.
- Ссылка «Конфиг изменился — Обновить» доступна без ключа API и тогда показывает ошибку разбора.
- Unreal переписывает конфиг при каждом выходе из игры, поэтому «Конфиг изменился» появляется почти после каждой сессии даже без изменений (сравнение по содержимому вместо времени записи убрало бы это).
- `UnrealScalability`: `sg.ResolutionQuality` = `NaN`/`Infinity` не отсекается (`double.IsFinite`); строка модели с `sg.*` без секции даёт дубль при слиянии; нет тестов на секцию в другом регистре и нечисловой масштаб.
- `ShowProvisionalFromFile` ловит только ошибки ввода-вывода; отмена во время разбора оставляет временные строки и не перестраивает таблицу.
- Нет теста `Restore` для JSON-конфига «ключ на строку»; `Restore`-часть теста свежести слабая (`File.Copy` сохраняет время `.orig`).
- README (раздел про откат) ещё описывает ручное восстановление копии, хотя есть кнопка «Вернуть исходный конфиг».
- Совет для старого файла переживает «Найти заново» с другим путём — «Применить» запишет старые ключи в новый файл.

Чат (уточнение совета, v0.8.0):
- Интерфейс не проверен вживую: Ctrl+V скриншота (`Clipboard.GetImage()` у WPF для части 32-битных источников даёт чёрную/прозрачную картинку), Win+H, перетаскивание, вид плавающей панели чата.
- `media_type` картинки берётся по расширению: PNG, сохранённый как `.jpg`, уйдёт как `image/jpeg` и получит 400 (тип можно брать из декодера).
- `ChatAttachments.Prepare` выполняется в UI-потоке — на PDF до 20 МБ окно может подвиснуть.
- Нет общего лимита на вложения в одном сообщении: два больших PDF дают запрос больше 32 МБ и 400 от API (черновик сохраняется).
- Маска секретов во вложенных текстовых файлах — только строки `ключ=значение`/`ключ значение`; компактный JSON и токены посреди строки лога уходят как есть.
- Пункт совета с ключом, похожим на секрет, не отправляется модели и пропадает из сохранённого совета после ответа в чате.
- Черновик и вложения в поле чата сбрасываются при открытии любой страницы игры.
- `Chat` в `library.json` хранится без ограничения длины (в запрос уходят последние 20 ходов).
- Нет тестов на Latin1-текст, проход `.gif`/`.webp` без перекодирования и отказ для слишком большой картинки; тест большого PNG дважды вызывает `Prepare`.
