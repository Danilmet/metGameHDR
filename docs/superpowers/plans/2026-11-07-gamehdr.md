# metGameHDR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Трей-приложение для Windows, которое само находит установленные игры, включает системный HDR на время игры и добавляет игры из папок и выбранные приложения в Steam с обложками.

**Architecture:** Сканеры источников складывают игры в `Library` (кэш JSON). `ProcessWatcher` раз в 2 с смотрит новые PID и проверяет их путь против папок игр; `HdrController` переключает HDR через DisplayConfig с задержкой выключения. Модуль Steam читает и пишет бинарный `shortcuts.vdf` своим парсером и кладёт обложки SteamGridDB в папку `grid`. WPF-окно и `NotifyIcon` поверх этого.

**Tech Stack:** .NET 8, WPF (`net8.0-windows`, `UseWindowsForms` ради `NotifyIcon`), xUnit, System.Text.Json, HttpClient, P/Invoke. Сторонних пакетов нет.

**Spec:** `docs/superpowers/specs/2026-11-07-gamehdr-design.md`

## Global Constraints

- .NET 8, `TargetFramework net8.0-windows`, `Nullable enable`, `ImplicitUsings enable`.
- Никаких NuGet-пакетов кроме xUnit в тестах.
- Пространства имён: `MetGameHDR.Scan`, `MetGameHDR.Watch`, `MetGameHDR.Steam`, `MetGameHDR.Ui`.
- Настройки и кэш: `%AppData%\metGameHDR\settings.json`, `library.json`, `log.txt`.
- Тик слежения 2 с, задержка выключения HDR 3 с.
- Без прав администратора, без WMI.
- Комментарии в коде только там, где поведение неочевидно.
- Коммит после каждой задачи; сообщения на английском, в конце строка `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. Папка одной игры — префикс папки другой (`C:\Games\Foo` и `C:\Games\Foobar`): процесс из второй не должен считаться первой. Тест в Task 2 (`FindByPath_MatchesOnSegmentBoundary`).
2. Путь процесса недоступен (системный или elevated процесс): слежение не падает, PID пропускается. Тест в Task 10 (`Tick_IgnoresPidsWithoutPath`).
3. Нет HDR-монитора, `IsEnabled()` возвращает `null`: контроллер ничего не переключает и не бросает. Тест в Task 11 (`Update_DoesNothingWhenHdrUnsupported`).
4. В `shortcuts.vdf` уже есть записи с полями, которых мы не знаем (`LastPlayTime`, `FlatpakAppID`, теги): после нашей записи они должны остаться байт в байт. Тест в Task 12 (`Roundtrip_PreservesUnknownFields`) и Task 13 (`Upsert_KeepsExistingAppIdAndFields`).
5. Подпапка в корне без единого подходящего exe (например `Saves`): в библиотеку не попадает. Тест в Task 7 (`Scan_SkipsFoldersWithoutExe`).
