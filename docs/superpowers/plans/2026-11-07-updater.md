# Апдейтер — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Приложение находит новый релиз на GitHub, сообщает о нём и по кнопке заменяет свой exe и перезапускается.

**Architecture:** Один статический класс `Updater` (проверка, загрузка, подмена файла), проводка в `App.StartTray` (таймер, балун, перезапуск), строка с кнопкой в блоке «Поведение» окна. Состояние не сохраняется.

**Tech Stack:** .NET 8 / WPF, `HttpClient`, `System.Text.Json`, `System.IO.Compression.ZipFile`, xUnit. Без новых NuGet.

**Spec:** `docs/superpowers/specs/2026-11-07-updater-design.md`

## Global Constraints

- Сторонних NuGet-пакетов нет; комментарии только там, где поведение неочевидно.
- Все строки UI по-русски, как в соседних контролах; цвета в XAML через `DynamicResource`.
- Отклонение от спеки: `Updater` держит собственный `HttpClient` с заголовком `User-Agent: metGameHDR` и без таймаута — у `MainWindow.Http` таймаут 15 с, которого на zip не хватит. Сигнатуры без параметра `HttpClient`.
- Сравнение версий — по трём компонентам (`Major.Minor.Build`): версия сборки четырёхкомпонентная (`0.1.0.0`), тег трёхкомпонентный (`v0.1.0`), иначе равные версии считались бы разными.
- Реальная проверка подмены exe и определения self-contained — только из терминала пользователя (`run_in_terminal`), не из песочницы.

## Review Focus

1. Тег не вида `vX.Y.Z` (например `latest`) → `Parse` возвращает `null`, не бросает. Тест в задаче 1.
2. В zip нет `metGameHDR.exe` → `Extract` бросает `FileNotFoundException`, текст уходит в строку окна. Тест в задаче 2.
3. Повторный запуск после обновления: `.old` и папка `update` удалены, отсутствие файлов не ошибка. Тест в задаче 2.
4. GitHub ответил 403 или сеть недоступна → только запись в лог, UI не меняется; следующая проверка по расписанию. Покрыто `catch` в задаче 4, ручная проверка в задаче 5.
5. Окно скрыто в момент обновления → новый процесс запускается с `--tray`, окно не выскакивает. Ручная проверка в задаче 5.

namespace MetGameHDR.Update;
public sealed record Release(Version Version, string AssetUrl, string PageUrl);

`Update_Click`: кнопка `IsEnabled=false`, `Content="Загрузка…"`, `await install()`; в `catch (Exception ex)`: `Log.Write($"Update: {ex}")`, `UpdateText.Text = $"Ошибка: {ex.Message}"`, кнопка снова `IsEnabled=true`, `Content="Обновить"`.

`App.StartTray`:
- первой строкой `Updater.Cleanup(Environment.ProcessPath!, AppPaths.UpdateDir)`;
- тело exit-колбэка трея вынести в локальную `void Stop()` (`timer.Stop(); FinishHdr(); tray!.Dispose();`), колбэк = `Stop(); Shutdown();`;
- `Version? notified`; `async Task CheckUpdatesAsync()`: `try { var r = await Updater.CheckAsync(); if (r == null) return; if (notified != r.Version) { notified = r.Version; tray.ShowInfo($"Доступна v{r.Version.ToString(3)}"); } window.ShowUpdate(r, () => InstallAsync(r)); } catch (Exception ex) { Log.Write($"Update check: {ex.Message}"); }`;
- `async Task InstallAsync(Release r)`: `var exe = Environment.ProcessPath!; var newExe = await Updater.DownloadAsync(r, AppPaths.UpdateDir); Updater.Swap(exe, newExe); var args = window.IsVisible ? "" : "--tray"; Stop(); instance!.Dispose(); Process.Start(exe, args); Shutdown();` — мьютекс освобождается до запуска, иначе новый экземпляр выйдет как второй;
- `var updateTimer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(10) }; updateTimer.Tick += (_, _) => { updateTimer.Interval = TimeSpan.FromHours(24); _ = CheckUpdatesAsync(); }; updateTimer.Start();`.
