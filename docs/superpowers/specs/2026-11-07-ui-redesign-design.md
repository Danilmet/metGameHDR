# metGameHDR — внешний вид окна

Статус: согласовано в обсуждении 2026-11-07.

## Цель

Заменить голое WPF-окно (вкладки, DataGrid) на библиотеку карточек с обложками в стиле OLED/Apple: чёрный фон в тёмной теме, одно стекло, один акцент. Тема следует за системной настройкой Windows. Логика в `Scan/`, `Watch/`, `Steam/` не меняется, кроме одного аддитивного поля (см. §2).

Не делаем: поиск и сортировку библиотеки, анимации, ручную смену обложки, собственный переключатель темы.

## 1. Компоновка

Окно `MainWindow` с прозрачным фоном и системным бэкдропом (§3). Сверху вниз:

- Шапка: сегмент-переключатель «Игры / Настройки» (RadioButton со стилем «пилюли»). Две страницы переключаются видимостью, без `TabControl`.
- Страница «Игры»: слева `ListBox` карточек с `WrapPanel` и вертикальной прокруткой, `SelectionMode=Extended`; справа панель деталей шириной 260 px, видима при ровно одной выбранной карточке.
- Низ страницы «Игры»: кнопки «Обновить», «Добавить приложение», «Добавить выбранное в Steam» и текст статуса — существующие `RefreshButton`, `AddAppButton`, `AddToSteamButton`, `StatusText`.

Карточка (`GameRow`): обложка 2:3 со скруглением 10 px, снизу название поверх тёмного градиента, в левом верхнем углу бейдж источника, в правом верхнем — тумблер HDR (`ToggleButton` в стиле переключателя, привязан к `HdrEnabled`, скрыт при `HdrApplies=false`), рядом с названием маленький значок Steam-статуса (`SteamText` непустой). Выбранная карточка обведена акцентом.

Панель деталей: имя, источник и Steam-статус, `ComboBox` exe (`ExeCandidates`, `MainExe`, доступен при `CanAddToSteam`), `TextBox` «Имя для поиска» (`SearchName`). Привязки те же, что сейчас в колонках DataGrid; `DataContext` панели — `SelectedItem` списка.

Страница «Настройки»: те же контролы (`RootsList`, `AddRootButton`, `RemoveRootButton`, `KeyBox`, `SteamUserBox`, `AutostartBox`, `TurnOffBox`), сгруппированные в карточки-строки: «Папки с играми» (список и две кнопки), «SteamGridDB» (ключ), «Steam» (аккаунт), «Поведение» (два тумблера).

Код окна (`MainWindow.xaml.cs`) меняется минимально: `GamesGrid` становится `ListBox`, добавляется запуск загрузки обложек после `RebuildRows`.

## 2. Обложки

Класс `Ui/Covers`: по игре возвращает путь к файлу обложки или `null`, и при необходимости докачивает в фоне.

Источники по приоритету:

1. Steam-игра: `<SteamPath>\appcache\librarycache\<appid>\library_600x900.jpg`, иначе старая плоская раскладка `<appid>_library_600x900.jpg`. Для этого `Game` получает необязательное поле `SteamAppId` (строка, `null` для остальных источников); `SteamSource` берёт его из поля `appid` манифеста. Единственное изменение вне `Ui/`, аддитивное: позиционные конструкторы в тестах не меняются, `library.json` старого формата читается.
2. Папка или приложение, уже добавленные в Steam: `<userdata>\<user>\config\grid\<appid>p.*`; appid из уже загруженного `shortcuts.vdf` (`ShortcutsFile.Find` + `AppIdOf`).
3. Кэш приложения `%AppData%\metGameHDR\covers\<имя>.<ext>`, где имя — безопасное имя файла из `InstallDir` (недопустимые символы заменены на `_`, обрезано, плюс короткий хэш для уникальности). Если файла нет и задан ключ SteamGridDB — загрузка в фоне через существующий `SteamGridDb` (`SearchAsync` по `SearchNameOf`, `BestImageUrlAsync("grids", id, "600x900")`), не более трёх параллельно; неудача запоминается в памяти до перезапуска.
4. Ничего не найдено: заглушка — иконка exe (`Icon.ExtractAssociatedIcon` → `BitmapSource`) на нейтральном фоне и название.

`GameRow` получает свойство `Cover` (`ImageSource?`) с уведомлением об изменении; картинки декодируются с `DecodePixelWidth` 300 и кэшируются в памяти по пути. Чистая функция выбора пути и формирования имени кэша покрывается тестами.

## 3. Тема и стекло

- Два словаря ресурсов `Ui/Themes/Dark.xaml` и `Light.xaml` с одинаковыми ключами (фон окна, поверхности карточек и панелей, текст, вторичный текст, акцент, цвет HDR). Тёмная тема: чистый чёрный фон, поверхности — белый с малой альфой. Акцент — системный синий, зелёный — только тумблер HDR.
- Тема при старте — из `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme`; смена ловится через `SystemEvents.UserPreferenceChanged` (категория General), словарь в `App.Resources.MergedDictionaries` заменяется.
- Стекло: после создания окна `DwmSetWindowAttribute(hwnd, DWMWA_SYSTEMBACKDROP_TYPE=38, DWMSBT_TRANSIENTWINDOW=3)` и `DWMWA_USE_IMMERSIVE_DARK_MODE=20` по теме; фон окна прозрачный через `WindowChrome` с `GlassFrameThickness=-1`. Если вызов вернул ошибку (Windows 10), фон окна становится сплошным цветом темы.
- Стили контролов (`Button`, `ToggleButton`-тумблер, `ComboBox`, `TextBox`, `ListBox`, `ListBoxItem`, `RadioButton`-сегмент, `ScrollBar`) — в `App.xaml` через `DynamicResource` к цветам темы. Шрифт Segoe UI Variable с откатом на Segoe UI.

## 4. Иконка

`tools/make-icon.ps1`: фон чёрный со скруглением, надписи «met» и «HDR» белые как сейчас, RGB-полоска тоньше (8 px). Перегенерировать `assets/icon.ico`. Зелёная точка трея без изменений.

## 5. Проверка

- Тесты: `Covers` — выбор пути для Steam-игры (новая и старая раскладка), для добавленной в Steam папки, для кэша, имя файла кэша безопасно и стабильно; `SteamSource` заполняет `SteamAppId`.
- `dotnet build` без предупреждений, `dotnet test` зелёный.
- Запуск из терминала пользователя: тёмная и светлая тема, стекло, обложки Steam-игр видны сразу, обложки SteamGridDB появляются в фоне, все кнопки работают, трей без изменений.
