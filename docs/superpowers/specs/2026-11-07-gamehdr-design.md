# GameHdr — дизайн

Статус: согласовано в обсуждении 2026-11-07.

## Цель

Windows-программа в трее, которая:

1. Сама находит установленные игры (Steam, Epic, GOG, Ubisoft Connect, EA app, Xbox/Store, указанные папки вроде `C:\Games`) и включает системный HDR, пока игра запущена, выключает после выхода.
2. Добавляет игры из папок и выбранные вручную приложения (например Discord) в Steam как non-Steam игры, одна запись на игру, с обложками из SteamGridDB.

Чем не устраивают готовые: AutoActions требует добавлять игры руками и перегружен интерфейсом; Steam ROM Manager непонятен и создаёт по несколько записей на игру.

Не делаем: RTX HDR / Windows Auto HDR per-app, добавление в Steam игр из других лаунчеров, темы, анимации, конфигурируемость сверх описанной.

## Стек

.NET 8, WPF, один exe, тесты на xUnit. Без сторонних библиотек, кроме стандартных (System.Text.Json, HttpClient); парсер VDF свой.

## 1. Слежение за процессами и HDR

Цикл раз в 2 секунды:

- Берёт список PID одним вызовом (`EnumProcesses`).
- Только у новых PID по сравнению с прошлым тиком запрашивает полный путь (`QueryFullProcessImageName` с `PROCESS_QUERY_LIMITED_INFORMATION`) и проверяет, что путь внутри папки игры с включённой галочкой HDR. Недоступные процессы (системные) пропускаются.
- Исчезнувшие PID вычёркиваются.

Состояние — множество «игровых» PID. Стало непустым → включить HDR. Стало пустым → выключить через 3 секунды задержки (защита от мигания при перезапуске exe лаунчером); если за это время появился новый игровой процесс, выключение отменяется.

HDR выключаем только если включили его мы (HDR был выключен в момент запуска игры). Переключение через DisplayConfig API (`DisplayConfigGetDeviceInfo` / `DisplayConfigSetDeviceInfo`, advanced color / HDR state) на все мониторы с поддержкой HDR.

Бюджет производительности: тик без новых процессов — микросекунды, память — список PID. Никаких WMI-подписок и прав администратора.

## 2. Сканер библиотеки

Игра: имя, папка установки, источник, главный exe (только для добавления в Steam), галочка HDR (по умолчанию включена).

Сканирование при старте и по кнопке «Обновить», результат кэшируется в JSON в AppData.

Источники:

- **Steam**: `libraryfolders.vdf` → `steamapps/appmanifest_*.acf` → имя и `installdir`. В Steam не добавляем.
- **Epic**: `%ProgramData%\Epic\EpicGamesLauncher\Data\Manifests\*.item` → имя, папка, exe.
- **GOG**: `HKLM\SOFTWARE\WOW6432Node\GOG.com\Games\*` → имя, папка.
- **Ubisoft Connect**: `HKLM\SOFTWARE\WOW6432Node\Ubisoft\Launcher\Installs\*` → папка; имя из папки.
- **EA app**: `HKLM\SOFTWARE\WOW6432Node\Electronic Arts\EA Desktop` / ветки игр → папка; имя из папки.
- **Xbox / Store**: `Get-AppxPackage` через PowerShell, фильтр на игры, `InstallLocation` в WindowsApps.
- **Папки**: корни из настроек, каждая подпапка — игра, имя из названия папки.

Главный exe для папочных игр: exe в корне папки с именем, ближайшим к имени папки; иначе самый большой. Отбрасываются `unins*`, `crash*`, `*redist*`, `vcredist*`, `dxsetup*`, `setup*`. В интерфейсе exe меняется вручную.

Приложения (Discord и т.п.): добавляются руками выбором exe или ярлыка, попадают только в список для Steam, за HDR не следят.

## 3. Запись в Steam и обложки

- Путь Steam: `HKCU\Software\Valve\Steam\SteamPath`. Аккаунт — подпапка `userdata\<id>`; по умолчанию последний вошедший (максимальный `timestamp` в `config\loginusers.vdf`, id = steamid64 − 76561197960265728), в настройках можно выбрать другой.
- Ярлыки: `userdata\<id>\config\shortcuts.vdf`, бинарный VDF. Свой парсер и писатель.
- Перед записью копия файла. Steam должен быть закрыт: проверяем процесс, просим завершиться (`steam.exe -shutdown`), ждём, пишем, запускаем обратно.
- Одна запись на игру, ключ — папка игры (StartDir), запасной — путь exe. Существующая запись обновляется, её appid и прочие поля сохраняются.
- Поля записи: `appname`, `exe` (в кавычках), `StartDir` (папка игры), `icon`, `LaunchOptions` пустой, `tags` пустой.
- Обложки: поиск в SteamGridDB по имени → лучшие по рейтингу grid (вертикальная 600×900 и горизонтальная), hero, logo. Сохраняются в `userdata\<id>\config\grid\` под именем из поля appid записи. Для новых записей appid = CRC32(exe в кавычках + appname) с установленным старшим битом, пишется в поле `appid`. Иконка из exe.
- Ключ SteamGridDB в настройках. Если игра не найдена — запись добавляется без картинок, в интерфейсе статус «без обложки», имя для поиска можно поправить и повторить.
- Запись атомарно: временный файл → переименование.

## 4. Интерфейс и настройки

Одно окно + иконка в трее.

Окно, вкладка «Игры»: таблица — имя, источник, галочка HDR; для папочных игр и приложений ещё «в Steam» (нет / добавлена / без обложки) и exe с выпадающим выбором. Кнопки: «Обновить», «Добавить приложение», «Добавить выбранное в Steam».

Вкладка «Настройки»: корни папок, ключ SteamGridDB, аккаунт Steam, автозапуск с Windows (ключ `Run` в реестре), галочка «выключать HDR при выходе из игры».

Трей: иконка показывает, включён ли HDR. Меню: открыть, пауза слежения, выход. Закрытие окна сворачивает в трей.

Настройки и кэш в `%AppData%\GameHdr\`.

## 5. Ошибки и проверка

- Ошибка одного источника не ломает скан: источник пропускается, запись в лог.
- Ошибка переключения HDR — всплывашка из трея, слежение продолжается.
- Лог в `%AppData%\GameHdr\log.txt`, ротация по размеру.

Тесты (xUnit):

- Парсер и писатель shortcuts.vdf: круговой пример байт-в-байт.
- Хэш appid против известных значений.
- Выбор главного exe по набору папок.
- Логика вкл/выкл HDR с задержкой на фейковых тиках и фейковом переключателе.
- Парсеры манифестов Steam и Epic на образцах.

Руками на машине: само переключение HDR, запись в Steam, обложки.
