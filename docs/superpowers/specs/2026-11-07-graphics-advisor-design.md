# metGameHDR — советчик по графическим настройкам

Статус: согласовано в обсуждении 2026-11-07. Решение: ADR `2026-11-07-game-settings-research.md`, вариант 2.

## Цель

Пользователь задаёт для игры цель — число кадров и приоритет (картинка / баланс / отзывчивость) — и получает список внутриигровых графических настроек со значениями под своё железо. Если у игры найден текстовый конфиг, настройки применяются в него одной кнопкой с подтверждением.

Не делаем: замер FPS, обратную связь «лучше/хуже», автоматические повторные запросы, выбор модели в интерфейсе, правку бинарных и реестровых конфигов, применение при запущенной игре.

## 1. Поток

1. В панели деталей игры секция «Графика»: цель (FPS — число, по умолчанию частота основного монитора; приоритет — три значения), кнопка «Подобрать», область результата, кнопка «Применить».
2. «Подобрать»: приложение собирает железо, ищет кандидаты конфигов, отправляет один запрос модели, показывает ответ: сводку и список «настройка — значение — причина». Ответ и время сохраняются на игру и показываются при следующем открытии; новый запрос только по кнопке.
3. «Применить» активна, когда в ответе есть путь к конфигу из числа кандидатов и список правок. Открывается окно «ключ: было → станет»; после подтверждения файл записывается. Если игра запущена — применение отказано с подсказкой закрыть игру.
4. Во вкладке «Настройки» карточка «Claude»: ключ API, FPS по умолчанию (пусто = частота монитора), приоритет по умолчанию. Без ключа секция «Графика» показывает подсказку вместо кнопки.

## 2. Железо

Собирается при каждом запросе, без прав администратора и без COM:

- Видеокарта и видеопамять: ветка класса дисплея в реестре (`DriverDesc`, `HardwareInformation.qwMemorySize`), первый адаптер с ненулевой памятью.
- Процессор: `ProcessorNameString` из реестра.
- ОЗУ: доступная физическая память из среды .NET, округлённая до ГБ.
- Монитор: текущее разрешение и частота основного дисплея через `EnumDisplaySettings`.
- Версия Windows.

Любой недоступный пункт передаётся как «неизвестно», запрос не срывается.

## 3. Кандидаты конфигов

До запроса приложение ищет текстовые файлы настроек и читает до трёх, суммарно до 100 КБ (большие обрезаются по началу):

- Unreal: `%LocalAppData%\*\Saved\Config\Windows*\GameUserSettings.ini`, где имя первой папки совпадает с именем игры, названием папки установки или именем exe без расширения (без учёта регистра и небуквенных символов).
- Корень папки установки: `*.ini`, `*.cfg` до 64 КБ.
- `Documents\My Games\<имя>` и `Saved Games\<имя>` по тем же правилам совпадения: `*.ini`, `*.cfg`, `*.txt` с «settings», «config», «video», «graphics», «user» в имени.

Кандидаты уходят модели с путями и содержимым; только их пути модель вправе вернуть как цель записи.

## 4. Запрос к модели

Messages API через собственный `HttpClient` (таймаут 3 мин), без SDK. Модель `claude-opus-5-5`, серверный веб-поиск (`web_search_20260209`, не более 5 поисков), структурированный вывод по схеме, серверный откат при отказе включён. Системный промпт: роль эксперта по оптимизации графики, правила — опираться на свежие материалы по игре и на реальные ключи из присланных конфигов, не выдумывать ключи, значения давать в формате меню игры, правки — только в один из присланных файлов.

Вход: игра (имя, источник, папка, exe), железо, цель, кандидаты с содержимым.

Схема ответа:

```json
{
  "summary": "string",
  "settings": [{ "name": "string", "value": "string", "reason": "string" }],
  "config": {
    "path": "string",
    "edits": [{ "section": "string|null", "key": "string", "value": "string" }]
  } | null,
  "notes": "string|null"
}
```

Ответ хранится как есть вместе с временем. Ошибки сети, HTTP, отказ модели (`stop_reason: refusal`) и невалидный JSON — текст в статусе секции и запись в лог, без всплывашек.

## 5. Запись в конфиг

Редактор строк, формат INI и близкие к нему текстовые конфиги:

- Файл читается байтами; BOM, кодировка (UTF-8 или UTF-16 по BOM, иначе UTF-8) и перевод строк (CRLF/LF по первому вхождению) сохраняются.
- Секция — строка `[Имя]`; `section = null` означает ключи до первой секции.
- Существующий ключ (без учёта регистра, первое вхождение в секции): заменяется только часть после разделителя; разделитель (`=` или пробел, с окружающими пробелами) берётся из строки.
- Отсутствующий ключ дописывается в конец секции перед следующей `[`; отсутствующая секция создаётся в конце файла. Новая строка — `key=value`.
- Все прочие строки, включая комментарии и дубли, не трогаются.

Перед записью: игра не запущена (по текущему списку процессов и папке игры), `<файл>.orig` создаётся один раз, если его нет, `<файл>.bak` перезаписывается каждый раз, затем атомарная запись. Окно диффа показывает каждую правку с текущим значением (или «нет»). Путь из ответа должен совпадать с одним из кандидатов, иначе «Применить» неактивна.

## 6. Данные

- `GameOverride`: `Goal` (FPS, приоритет; null — глобальные), `Advice` (ответ, время запроса). Хранится в `library.json`, старые файлы читаются без миграции.
- `Settings`: `ClaudeApiKey`, `DefaultFps` (null — частота монитора), `DefaultPriority`. Открытым текстом, как ключ SteamGridDB.

## 7. Структура

```
src/metGameHDR/Advice/
  Hardware.cs       сбор железа
  ConfigFinder.cs   кандидаты конфигов
  ClaudeClient.cs   запрос и разбор ответа
  IniEditor.cs      правки текста конфига
  Advisor.cs        склейка: собрать → спросить → сохранить; применить
src/metGameHDR/Ui/
  секция «Графика» в панели деталей MainWindow, карточка «Claude» в настройках, окно диффа
tests/metGameHDR.Tests/Advice/
```

## 8. Тесты

- IniEditor: замена значения с `=` и с пробелом, дописывание ключа в секцию и в конец, создание секции, сохранение BOM/UTF-16/CRLF, комментарии и чужие строки байт-в-байт.
- ClaudeClient: фейковый `HttpMessageHandler` проверяет заголовки, модель, инструмент поиска, схему; разбор валидного ответа, `refusal`, невалидного JSON.
- ConfigFinder: временные папки с Unreal-шаблоном и корнем игры, совпадение имён, лимиты размера.
- Advisor: отказ применять при запущенной игре на фейковом списке процессов; путь не из кандидатов — применение недоступно; `.orig` создаётся один раз.
- Hardware: сбор не бросает исключений, поля заполнены или «неизвестно».

Руками: реальный запрос на одной Unreal-игре с применением и на игре без текстового конфига.
